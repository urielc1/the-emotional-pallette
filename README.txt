THE EMOTIONAL PALLETTE — 4-PAGE EDITION

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Use the navigation: Home, Explore artworks, The research, Sources & credits.

HOW TO EDIT IN VISUAL STUDIO CODE
1. Open Visual Studio Code (blue icon, not Visual Studio).
2. File > Open Folder > select the extracted the-emotional-pallette folder.
3. Open index.html to edit the home page.
4. Open explore.html to edit the gallery structure and placeholder text.
5. Open research.html to edit research writing.
6. Open sources.html to edit citations and disclosure.
7. Open script.js to edit artwork filenames, interpretation options, and context.
8. Open styles.css to edit layout, typography, and colors.
9. Save Ctrl+S and refresh the browser Ctrl+R.

IMAGE FIX
The incorrect 'Starry_Night.jpg' reference was replaced with a Wikimedia Commons file page titled
'Van Gogh - Starry Night - Google Art Project.jpg'. Images are still remote and need internet.
For a reliable local image: download the verified image from Wikimedia Commons to an 'images' folder,
then in script.js replace the Starry Night image property with 'images/starry-night.jpg'.

If you have a local photo, always verify it actually shows the intended artwork before using it.
